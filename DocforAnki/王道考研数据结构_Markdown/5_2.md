01. 下列关于二叉树的说法中，正确的是( )。

;;;
A. 度为2的有序树就是二叉树
B. 含有n个结点的二叉树的高度为$\lfloor\log n\rfloor+1$
C. 在完全二叉树中，若一个结点没有左孩子，则它必是叶结点
D. 含有n个结点的完全二叉树的高度为$\lceil\log n\rceil$
;;;C

**完全二叉树中无左孩子的结点必是叶结点**
完全二叉树高度应为$\lfloor\log_2(n+1)\rfloor$或$\lfloor\log_2n\rfloor+1$

01. 在一棵完全二叉树中，含有n0个叶结点，当度为1的结点数为1时，该树的高度是多少？当度为1的结点数为0时，该树的高度是多少？
***
由$n_0 = n_2 + 1$得$n_2 = n_0 - 1$
总结点$n = 2n_0 + n_1 - 1$
1. $n_1=1$时：$h = \lceil\log_2(2n_0+1)\rceil$
2. $n_1=0$时：$h = \lceil\log_2n_0\rceil + 1$

+++

02. 一棵有n个结点的满二叉树有多少个分支结点和多少个叶结点？该满二叉树的高度是多少？
***
满二叉树$n_1=0$
叶结点数：$m = (n+1)/2$
分支结点数：$n - m = (n-1)/2$
高度：$h = \log_2(n+1)$

+++

03. 已知完全二叉树的第9层有240个结点，则整个完全二叉树有多少个结点？有多少个叶结点？
***
前8层满：$2^8-1 = 255$
总结点数：$255 + 240 = 495$
第8层叶结点：$(256 - 240)/2 = 8$
总叶结点：$8 + 240 = 248$

+++

04. 一棵高度为h的满m叉树：
1)各层的结点个数是多少？
2)编号为i的结点的双亲结点编号？
3)编号为j的结点的第k个孩子编号？
4)编号为j的结点有右兄弟的条件？
***
1. 第k层结点数：$m^{k-1}$
2. 双亲编号：$\lfloor (i-2)/m \rfloor + 1$
3. 第k孩子：$(j-1)m + k + 1$
4. 有右兄弟条件：$(j-1)\%m \neq 0$，右兄弟=$j+1$

05. 设计算法求顺序存储二叉树中编号i和j的结点的最近公共祖先结点的值
***
```c
ElemType Comm_Ancestor(SqTree T, int i, int j) {
     while(i != j) {
         if(i>j) i = i/2;
         else j = j/2;
     }
     return T[i];
}
```

时间复杂度：$O(\log n)$

06. [2016统考真题]正则k叉树T：
1)有m个非叶结点时叶结点数？
2)高度h时的最多/最少结点数？
***
1. 叶结点数：$(k-1)m + 1$
2. 最多结点：$\frac{k^h-1}{k-1}$（满k叉树）
3. 最少结点：$1 + (h-1)k$（单支树）
