01. 一个算法应该是（ ）。

;;;
A. 程序
B. 问题求解步骤的描述
C. 要满足五个基本特性

05. 以下算法的时间复杂度为（ ）。

```c
void fun(int n) {
    int i = 1;
    while (i <= n)
        i = i * 2;
}
```

;;;
A. $O(n)$
B. $O(n^{2})$
C. $O(n\log n)$
D. $O(\log n)$
;;;D
***
基本语句 `i=i*2` 执行次数 $t$ 满足 $2^{t}\leq n$，即 $t\leq\log_{2}n$，故 $T(n)=O(\log n)$

06. 有以下算法，其时间复杂度为（ ）。

```c

}
```

;;;
A. $O(n)$
B. $O(n\log n)$
C. $O(\sqrt[3]{n})$
D. $O(\sqrt{n})$
;;;C

```c
for (i = n - 1; i > 1; i--)
```

```c
if (n >= 0)
```

B. $O(n^{2})$

09. 以下算法中加下画线的语句的执行次数为（ ）。

```c
int m = 0, i, j;
for (i = 1; i <= n; i++)
    for (j = 1; j <= 2 * i; j++)
        m++;
```

;;;
A. $n(n+1)$
B. $n$
C. $n+1$
D. $n^{2}$
;;;A
***
执行次数：$\sum_{i=1}^{n}\sum_{j=1}^{2i}1 = \sum_{i=1}^{n}2i = n(n+1)$

10. 下列函数代码的时间复杂度是（ ）。

```c
int Func(int n) {
    if (n == 1) return 1;
    else return 2 * Func(n / 2) + n;
}
```

;;;
A. $O(n)$
B. $O(n\log n)$
C. $O(\log n)$
D. $O(n^{2})$
;;;C
***
递归树深度 $t$ 满足 $n/2^t=1$，即 $t=\log_{2}n$，每次递归 $O(1)$，总体 $O(\log n)$

11. 【2011统考真题】设 n 是描述问题规模的非负整数，下列程序段的时间复杂度是（ ）。

```c

while (x < n / 2)

```

```c
    return n * fact(n - 1);

```

;;;

B. $O(n)$
C. $O(n\log_{2}n)$
D. $O(n^{2})$
;;;B

13. 【2014统考真题】下列程序段的时间复杂度是（ ）。

```c
count = 0;
for (k = 1; k <= n; k *= 2)
    for (j = 1; j <= n; j++)
        count++;
```

;;;
A. $O(\log n)$
B. $O(n)$
C. $O(n\log n)$
D. $O(n^{2})$
;;;C
***
外层循环执行 $\lfloor \log_{2}n \rfloor+1$ 次，内层循环固定 $n$ 次，总次数 $n(\lfloor \log_{2}n \rfloor+1)=O(n\log n)$

14. 【2017统考真题】下列函数的时间复杂度是（ ）。

```c
int func(int n) {
    int i = 0, sum = 0;
    while (sum < n) sum += ++i;
    return i;
}
```

;;;
A. $O(\log n)$
B. $O(n^{1/2})$
C. $O(n)$
D. $O(n\log n)$
;;;B
***
循环次数 $t$ 满足 $\sum_{k=1}^{t}k < n$，即 $t(t+1)/2 < n$，得 $t=O(\sqrt{n})$

16. 【2022统考真题】下列程序段的时间复杂度是（ ）。

```c
int sum = 0;
for (int i = 1; i < n; i *= 2)
    for (int j = 0; j <= i; j++)
        sum++;
```

;;;
A. $O(\log n)$
B. $O(n)$
C. $O(n\log n)$
D. $O(n^{2})$
;;;B
***
总执行次数 $T = \sum_{k=0}^{\log_2 n} (2^k+1)$，等比级数和 $S=2^{t+1}-1 + t \approx 2n$（$t=\log_2n$），故 $O(n)$
